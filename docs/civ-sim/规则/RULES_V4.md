## 〇、一页看完

**目标**【定 11-17、11-18】：一个开局以后不用再缝补、可以专心看剧情的世界。剧情的主角是九家 AI 控制的一个个人。

**和第三世界的五处不同**

| | 第三世界 | 第四世界 |
|---|---|---|
| 规则 | 十三个引擎规则开关在 1694 到 3795 年间陆续打开 | 全部从第 0 年起生效，开局后不加规则 |
| 数值怎么定 | 开局后边推边调，靠真模型一轮轮验 | 开局前用不调模型的批量推演校准，再彩排一次 |
| 重心 | 文明意志的五十年、一百年方略 | 人：下凡、场面、成败、恩仇 |

| 收场 | 没有收场，推到信息时代 | 工业霸主满 100 年，或第一个工业国出现后 600 年封卷 |

**开局前四步**：校准（不调模型）→ 做“人”这一层的新机制 → 彩排 100 年（调模型）→ 冻结开局。细目见第十三节。

**第十五节的六条**已定，全部按默认。

## 一、三条总原则

1. **规则一次定死。**【定 11-18：不要一直缝缝补补】所有规则从第 0 年起生效。开局以后不加机制、不调数值。观察者给 AI 派任务、给世界加事件不在此限：那是记进存档的天意，不是改规则（第十节）。
2. **只修 bug。**【提】程序没按本书做，是 bug，可以修。本书写的规则跑出来不满意，不是 bug，不改，记进“第五世界备忘”。唯一的例外是世界停摆：推进报错、存不了档、所有国家都亡了。
3. **剧情优先。**【提】新机制只做一种：直接让 AI 人物的故事更好看的。给世界加真实感的新子系统一律不做。

## 三、世界

### 3.1 时间线
- 第 0 年起只跑引擎，不调模型。推到 1000 至 2000 年之间由你喊停，我按当时的地图给九席的落点建议，你定了再入场。【定 11-11】入场那年改元。
- 入场以后：意志每 50 年议事一次；人在世时按第六节的镜头走。（实际入场时改为每 100 年，见 3.1a。）

### 3.1a 实际的入场（2026-11-19，观察者定）
观察者原话：“我希望 ai 在倒数的 9 个里面”“然后他们以天意存在 800 年（每 100 年给一次意见），推到 2000 年作为元年。这个时候我来观察情况。或者你立 9 个民族的国家也行”。
- **世界**：种子 111，预设写实·二，十五条规则全部从第 0 年起。纯引擎推到 1200 年，当时 12 国、14 个部落。
- **九个民族各一国**：渠善部、有鹤部、纳萨马尔部、阿绝部、莱纳斯城邦、景澜部六国是现成的；有雕、济、扎克内三族当时还没有国家，1200 年以天意在各自部落的治所各立一国（有雕部、济部、扎克内城邦）。阿绝人、莱纳斯人各有几个国家，取以族名为号、立国最久的那个。没有被选的是维纳维亚人（翁古特共和国，24 州，当时的头号大国）和翁古特人（塞卢里亚城邦）。
- **九席都是国家席位，没有宗教席位。**这改掉了第四节的“八国一教”：GPT 这一局附景澜部。当时世上只有一个大教（照冥教，1 国奉它）。
- **谁去哪国**是助手用世界种子 111 抽的签：混元→渠善部，鲸鱼→有鹤部，克劳德→纳萨马尔部，智谱→阿绝部，Kimi→莱纳斯城邦，GPT→景澜部，MiMo→有雕部，海螺→济部，哈基米→扎克内城邦。
- **直接以文明意志入场**（1201 年）：不寄身人物，不过“第一世”。入场当年议事一次，此后每逢整 100 年议事（1300、1400……1900），其间不叫醒。按第五节：意志不写自由方案、不能改附身；所附之国被打亡照 6.12 降为人间体（没有前世的，是“故国遗民之后”）。
- **改元**：世界第 2000 年为纪元元年，此前称纪元前。到 2000 年停下，由观察者看情况再定下一步。
- **下凡开关没开**。1201 到 2000 年这八百年里，除了失国的人间体，没有 AI 人物在世。
- **模型**：沿用第三世界现用的九个；裁判 gpt-6.1-sol（意志不写自由方案，议事时不叫裁判）。
- 入场前后的存档备份在 `saves-backup/第四世界.bak-1119-*`。
- **进度（2026-11-19）**：观察者中途改为“1700 年先停下回顾”。世界停在 1701 年，1201 至 1700 共议事六轮，下一轮在 1800 年；尚未改元。济国 1522 年亡于景澜国、扎克内共和国 1549 年亡于巴莱特汗国，海螺、哈基米两席照 6.12 降为人间体。下凡开关没开时，人间体沿用第三世界“一生只议一次”的规矩。
- 首轮议事重跑过两次（鲸鱼、哈基米的回答格式程序没读出来，修了解析并加了“读不出就请它重交一次”），作废的两份存档留在 `saves-backup/第四世界.作废-1119-*`。
- 第一个工业国的目标年份是 2400 至 2800 年（靠校准）。
- 收场见第九节。按这些数，世界大约在 3000 至 3400 年封卷。

### 3.2 选种子【做】
开局前用 8 到 10 个种子只跑引擎推到收场，挑同时满足下面几条的：
- 至少两块像样的大陆；煤、铁不集中在一处。
- 前 1500 年没有一国独大。
- 第一个工业国落在 2400 至 2800 年。
- 入场前后至少有三个大教，并且不同大教的国家之间有接壤。【提】这一条是今天加的：第三世界各教连成一片，宗教冲突起不来。

### 3.3 底层规则：全部从第 0 年起生效【有】

| 规则 | 一句话 |
|---|---|
| 正常天灾 | 饥荒、瘟疫、地震照常发生 |
| 新立国规则 | 新国有站稳期；被强邻宣战可以当场称臣 |
| 治理极限与借道援救 | 国土超出管得住的州数就少扩张、易分裂；盟国可以借道来救 |

| 自由结盟 | 结盟少设门槛【定 11-12】 |
| 农耕守势 | 农耕国在本族的州上防守加 15% |
| 发展倾向 | 掌权者越重发展，本国发展越快 |
| 疆土与封建 | 分封、朝贡和藩属两档、合众立国、地形进战争、同教相亲【定 11-12】 |
| 审势与立国 | 开战看形势；无主城满一万人可立国；小国结邦联、同族合联邦 |
| 盟约看交通 | 盟约不设上限，但要接壤或国都够近 |
| 国用与国势 | 府库就是真国库；入不敷出欠饷，兵力逐年打折；积欠五年、十年出事 |

| 分项技术 | 33 项技术按国家记，学会就跳一档；经接壤、航线、盟约、同教、交战传播 |
| 教义 | 见第七节 |
| 游牧寇边、大举进犯 | 游牧国洗劫边州，遇弱邻直接宣战 |

**要说清的风险**：这些规则在第三世界都是推了一千多年以后才陆续打开的，“从第 0 年起全开”这个组合一次都没跑过。所以校准是第一步，不能跳。

### 3.4 设计稿里有、这次不做的【提】

| 不做的 | 理由 |
|---|---|
| 国债、人口转型、工业时代检查间隔减半、战争形态变化 | 都是新子系统，和“专心剧情”冲突 |

| 广纳与闭关国策、接触疫病、跨洋远征（圣战的陆路远征已有） | 同上 |
| 快照续推 | 读档已只要几秒 |

## 六、人：剧情在这里

### 6.1 下凡与归位【有】【定 11-17】
- 意志在议事时自己决定下凡，从本国三个不在君位的少年里挑一个。宗教席位降为奉本教之国的教门子弟。
- 人在世时，这一席不议事，本国照旧方略走到期满。
- 人死后意志归位，冷却 50 年才能再下凡。
- 你可以召集各席同时下凡，不受冷却限制。
- 【提】【做】冷却期满那一年如果不是议事年，单独问它一次要不要下凡。不加这条，每席平均要多等 25 年。

### 6.2 意志和人之间只有一句话【有】【定 11-17】
- 下凡时意志给这个人留一句话，至多 40 字，写了不能改。人只当是自幼常梦见的一句话。
- 人只记得连着寿终、紧接着再来的前几世。横死，记忆就断，下一个人只剩那句话。意志什么都不丢。

### 6.3 提示词三层【做】
1. **本性**：第四节那四行，固定。
2. **此世身份**：出身、家境、所在之国、眼下的大事、身边人（6.9）。程序生成。
3. **此世私愿**（6.4）：AI 自己立。

### 6.4 私愿【提】【做】
成年后第一次议事，AI 给这一世立一到两件私事，只能从下面几类里选，这样程序才检验得了：

| 类 | 例 |
|---|---|
| 官位 | 做到首辅 |
| 得国 | 做一国之主 |
| 婚姻 | 娶某家之女 |
| 复仇 | 让某人失势或身死 |
| 庇护 | 保某人活到某年 |
| 传承 | 让某个后人继位，或留下一部书 |
| 土地 | 让本国取回某州 |
| 信仰 | 让某国改奉某教 |

每次简报报进度；身后小传写成没成。一世可以改一次。

**成算要写出来**【提】【做】：密谋、自立、投奔、求婚这几样，只要眼下走得通，简报里就各给一行：成算是十拿九稳、五五开还是凶多吉少，败了多半是什么下场。只给档位词，不给数字。

### 6.6 场面【提】【做】
AI 人物主动发起的一场具体的戏。

- **种类**：求见、设宴、密谈、对质、提亲、托孤、结义、送别、决斗、行刺。
- **对方是另一位 AI 人物**：当年加开，两人对话至多四个来回，每句至多 120 字；裁判当旁白收尾。
- **对方不是 AI**：裁判替他答一个来回。
- **结果要落到实处**：成败按 6.7 定档；可以带来联姻、任命、投奔这类引擎里的变化，可以立私约（6.10），一定会记进恩仇账（6.9）。
- **限额**：每人每年至多发起一场、应两场；一世至多发起 12 场。
- **相遇**：两位 AI 人物同在一国、两国交战或通使时，简报里各自写一行对方其人如何。不告诉对方背后是谁。
- 对话全文存进“场面录”，是分集的主要材料。

### 6.7 成败三档【提】【做】
- 每件要判的事分三档：成、成而有代价、败。
- **档位由程序掷骰**，不由裁判拍板。成算看这件事的类别、他的资望和官职、本国的动荡和战事、与对方的恩仇。
- 裁判只写经过，并在程序给的档位里定代价的内容。
- 起始目标（彩排时校准）：密谋、自立、行刺这类高风险的事，败三到五成；日常的事，败不过一成；九个人里一世横死一到三个。

### 6.8 处境【提】【做】
失败不等于沉默。下面几种处境都有期限和脱身的办法，处境里的人照样议事，并且改成每年一议：

| 处境 | 期限 | 还能做什么 |
|---|---|---|
| 下狱 | 1 到 10 年 | 写书、传话、求赦、越狱 |
| 流放 | 到赦免为止 | 在流放地经营、逃走、等召回 |
| 负伤 | 1 到 3 年 | 照常，但办事打折 |
| 为质 | 到换回为止 | 在那国结交、逃归 |
| 通缉 | 到改朝或赦免 | 流亡、投奔、潜回 |

### 6.9 身边人与恩仇账【提】【做】
- **身边人**：每个人物有 5 到 8 个固定的人：家主或父母、配偶、一两个子女、上司或君主、对头、心腹、挚友。先用引擎史册里的人（君主、宗室、名臣、将领、后妃），不够的由外层造，有名有姓，存进存档；会老会死，死了补位。每次简报列出他们的近况和对他的态度。
- **恩仇账**：程序记下谁在哪一年对他做了什么，是恩是仇、轻重如何。来源是场面的结果、密谋、举荐、背约、杀亲。再遇到这个人时简报提醒，也影响成算。写进遗嘱或家书的仇，后人读得到。

### 6.10 私约【提】【做】
场面里可以立约：盟誓、婚约、托孤、分利。程序登记双方、内容、期限。背约记进史书和对方的恩仇账，资望受损。

### 6.11 镜头【有】【定 11-17】
- 平时十年一议；AI 可以自约 1 到 9 年后再议，其中五年以内的短约一世至多 8 次。
- 得位、失位、亡国、易地当年叫醒。
- 【提】【做】再加三种当年叫醒：落入处境、有人对他发起场面、兵临所在之城。

### 6.12 失国与血脉【有】【定 11-16】
- 所附之国被打亡，意志不会自动得到别的国家。它降为人间体，一个无官无兵的少年，是前世那一血脉的后人。
- 只有他做了一国之主，意志才附上去。不限本族，鸠占鹊巢也算。
- 没得国就死了，隔 20 年再降一回。遗民每十年可能起事复国一次。
- 本族一个人都不剩，这一席出局。

## 九、收场与进度榜

### 9.1 霸业【定 11-17】，判定程序【做】
某一国同时满足下面五条并连续维持：满 50 年记“称霸”，满 100 年“霸业成”，封卷。

| 条件 | 起始值 |
|---|---|
| 工业化 | 有蒸汽机、铁路、电报、征兵制 |
| 体量 | 国力占天下 25% 以上 |
| 断层领先 | 国力是第二名的 1.5 倍以上 |
| 跨洋存在 | 在两块以上大陆有领土或藩属 |
| 内部稳 | 积欠不满十年，动荡不在最高一档 |

- 掉下来有 10 年宽限。易代、改制算同一国；被灭或分裂算断。
- **保底**：第一个工业国出现后 600 年还没人满 100 年，就封卷；持续最久的那段霸权（至少 50 年）的主人算胜者，没有就记“列强并立”。
- 25% 和 1.5 倍在第三世界够不着，第一轮校准里八个种子也都是 0 年。【定 11-18】观察者不看 AI 达没达成，条件不改，只当进度榜；世界多半走保底封卷。

### 9.2 进度榜【有】【定 11-16】
一统、富庶、开物、圣教、新学、太平、万世七项照旧算，只当看板，不决定收场。

### 9.3 AI 知道什么【提】
天下谁最强是公开的，各席都看得到。“满 100 年就封卷”不告诉它们。依据是你 11-09 定的：AI 不能知道胜利条件。

## 十、观察者：天命与世界事件

【定 11-18】为了故事性，观察者中途可以给 AI 派任务、给世界加事件，不设次数上限。两样都从下达那年起生效，不改已经推出来的历史；大事表一律标【天意】，终编里单列一章。

### 10.1 已有的【有】
- 干预面板十二种：宣战、结盟、议和立约、割州、立国或起义、灭国、天灾（瘟疫、饥荒、地震水旱）、保全、禁止分裂、不许扩张、变法图强、定方针。
- 另有四种：几国合邦、扶持复国、指定某教的教义、召集各席同时下凡。
- 给裁判的纠正指令；改某一席的人设和模型。

### 10.2 给 AI 的话【定 11-18】【有】
世界照常运行。观察者想让 AI 做什么，告诉助手，助手照办，只有两条路：
- **传话**（一次性）：把一段话直接写给某一席、几席或全部（`Game.say`，接口 `POST /api/say`，参数 to、text、wake）。下次轮到它时出现在简报最前面，送到即止。
  - 写给意志：下次议事时看到，最长要等一个议事间隔（50 年）。
  - 写给它在世的人：下次议事时看到；可以让他当年就议。他不知道自己背后有意志，所以这段话要用世间的话写，他看到的是“心里反复响着的几句话”。
  - 原话照登，不经裁判。听不听由 AI 自己定，程序不追进度、不设赏罚。传话记在存档里（`cfg.heavenWords`），不进大事表，别的席位看不到。
- **写进人设**（长期）：改某一家的人设，至多 400 字，此后每一轮都带着。改了以后它的会话重开。

### 10.3 世界事件【有】
- 用 10.1 现成的干预。接口另外还认六种面板上没有的：迁都、大迁徙、驻留、让某人去世、摄政、索地，要用时由助手直接下。
- 不做的：立君主、改君主倾向、任将任臣、联姻这四种命令外层接口不认；观察者自己写一段话当世界事件的入口也不做。想让世上多一件“事”，用传话告诉相关的席位，或用现成的天灾、立国、宣战。

### 10.4 不变的
- 开局后不动规则开关，不改引擎。
- 喊停入场、定九席落点、封卷由观察者定。

## 十一、史官与产出【做】

- **小传**：每一世结束自动出一篇，三五百字：出身、私愿成没成、几场要紧的场面、怎么死的、留下什么。
